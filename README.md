# ACTA

Private Club — New Approach

ACTA is a private members club website concept focused on delivering notices, preserving evidence, and recording responses. This repository contains its standalone frontend.

The original site at `ikhnaie.anatoliim.chatgpt.site` is a separately hosted project. This repository does not control or automatically replace that deployment. No live backend, membership system, or BSV blockchain anchoring is provided by this frontend.

## Run locally

Open `index.html` in a browser, or serve the folder with any static server (e.g. `python -m http.server 8000`).

## Deployment

Deploy as a static site via GitHub Pages or Cloudflare Pages after reviewing settings, content, and links.
